Evidence Plan for Posture Thresholds (v1, provisional)

This document lists the current thresholds used for posture classification and measurement severities. These values are provisional and intended to be refined with a PubMed literature review.

Current thresholds (config/posture-thresholds.ts):
- CVA normal: 50–60° (adult, sagittal)
- Forward head offset (% of shoulder width): normal ≤8%, mild ≤12%, moderate ≤16%
- Trunk tilt from vertical: normal ≤5°, mild ≤10°, moderate ≤15°
- Pelvic translation (% of shoulder width): normal ≤5%, mild ≤10%, moderate ≤15%
- Shoulder tilt from horizontal: normal ≤2°, mild ≤4°, moderate ≤6°
- Shoulder height asymmetry (% of shoulder width): normal ≤2%, mild ≤4%, moderate ≤6%

Next steps:
- Collect normative CVA by age/sex and define age-adjusted bands.
- Identify quantitative proxies for thoracic kyphosis and lumbar lordosis in 2D to better separate kypholordosis/flat-back in Kendall classification.
- Update this file with citations and adjust thresholds accordingly.
